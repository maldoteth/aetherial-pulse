# Fansite

An earlier build of the DeHub fan platform: social feed, creator pages and Supabase-backed auth, deployed on Netlify behind Cloudflare.

## Tech stack

- React + TypeScript, built with Vite
- Tailwind CSS and shadcn/ui

## Getting started

```sh
git clone https://github.com/maldoteth/aetherial-pulse.git
cd aetherial-pulse
npm install
npm run dev
```
